# Komentář k zákonu č. 274/2001 Sb., o vodovodech a kanalizacích pro veřejnou potřebu a o změně některých zákonů

Otevřený komentář k zákonu o vodovodech a kanalizacích — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; vlastnictví a provozování vodovodů a kanalizací, přípojky, technické požadavky a jakost vody, dodávka vody a odvádění odpadních vod, vodné a stočné, ochranná pásma, působnost úřadů, přestupky a ochrana odběratele.
